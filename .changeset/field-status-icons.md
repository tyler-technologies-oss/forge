feat(field): fields show an error icon when `invalid` (or `theme="error"`) and a warning icon when `theme="warning"`. The icon sits between the input and the `end` slot, is hidden from assistive technology, and can be hidden with `--forge-field-status-icon-display: none`. Adds the `status-icon` part and the `--forge-field-status-icon-display`, `--forge-field-status-icon-size`, `--forge-field-status-icon-error-color`, and `--forge-field-status-icon-warning-color` tokens
