A dialog container for hosting an AI chat experience. On wide viewports it is a draggable, non-modal panel anchored to the bottom-right of the screen. When `expanded`, or on viewports 768px wide or narrower, it becomes a full modal dialog.

<Canvas of={AiDialogStories.Demo} />

## Usage

Place your chat content in the default slot and control visibility with `open`, or the `show()`, `close()` and `toggle()` methods.

```html
<forge-ai-dialog label="Support assistant">
  <forge-ai-chat-interface>...</forge-ai-chat-interface>
</forge-ai-dialog>
```

Listen for `forge-ai-dialog-close` to react when the dialog is dismissed (including with the Escape key), and `forge-ai-dialog-fullscreen-change` to adapt your content when the dialog switches between panel and fullscreen layouts.

## Accessibility

The `label` property (default: `"AI Assistant"`) is applied as the dialog's `aria-label`. Set it to describe the slotted content.
