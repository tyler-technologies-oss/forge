The layout for a chat: a header, a scrolling message area, and a prompt. Use it as the frame you place messages and a `forge-ai-prompt` in.

Messages go in the default slot. The `header`, `suggestions`, `attachments`, `prompt` and `disclaimer` slots take the matching components. Call `scrollToBottom()` to scroll the message area to the latest message.
