A button that lets the user choose files to upload, either through the file dialog or by dropping files onto it. Use it to add attachments to a prompt or conversation. It validates each file and reports the result with events, and your app handles the files.

<Canvas of={AiFilePickerStories.Demo} />

## Usage

```html
<forge-ai-file-picker accept=".pdf,.txt" multiple></forge-ai-file-picker>
```

### Events

`forge-ai-file-picker-change` fires once for each accepted file. Its detail is `{ file, timestamp }`, where `file` is the `File` and `timestamp` is when it was selected. Without `multiple`, only the first file from a selection or drop is considered.

`forge-ai-file-picker-error` fires for each rejected file. Its detail is `{ type, message, filename }`, where `type` is `'size'` (over `maxSize`) or `'duplicate'` (the name is in `selectedFiles`).

The picker does not track what has been chosen. Pass the names you have already accepted to `selectedFiles` to have repeats rejected.

### Variants

The default `icon-button` variant shows a plus icon with an "Add file(s)" tooltip. Use the `icon` slot to replace the icon. The `button` variant shows a text button and uses the default slot for its label.

<Canvas of={AiFilePickerStories.Button} />

### Restrictions

`accept` limits the file types, and `maxSize` is in bytes (10 MB by default).
