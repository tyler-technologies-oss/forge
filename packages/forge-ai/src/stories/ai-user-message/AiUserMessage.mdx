## Toolbar and editing

The toolbar is only shown when `message-id` and `timestamp` are both set. It offers copy, resend, and edit actions, and shows the time. Edit opens an inline editor; set `content` to the original text to seed it. While `streaming` is set, resend and edit are hidden.

```ts
message.addEventListener('forge-ai-user-message-copy', evt => console.log(evt.detail.messageId));
message.addEventListener('forge-ai-user-message-resend', evt => console.log(evt.detail.messageId));
message.addEventListener('forge-ai-user-message-edit', evt => console.log(evt.detail.messageId, evt.detail.content));
```
