A scrolling list of chat messages. It renders user messages, assistant responses (with markdown), tool calls, client-only notices, an empty state, and a thinking indicator.

<Canvas of={AiMessageThreadStories.Demo} />

## Usage

Set `messageItems` to the list to render. Each item is a `message`, `assistant` response or `toolCall`. Pass `tools` (a map of tool name to definition) to render tool call results with custom renderers.

```js
thread.messageItems = [{ type: 'message', data: { id: '1', role: 'user', content: 'Hello', timestamp: Date.now(), status: 'complete' } }];
```

The thread scrolls to the latest content automatically while the user is at the bottom, and shows a scroll-to-bottom button otherwise. Set `auto-scroll="off"` to disable, or call `scrollToBottom()`.

Set `enable-reactions` to show thumbs up and down on assistant responses, and `show-thinking` to show a thinking indicator while waiting.

The thread emits `forge-ai-message-thread-copy`, `-resend`, `-thumbs-up` and `-thumbs-down` for assistant responses, and `-user-copy`, `-user-resend` and `-user-edit` for user messages. Each detail includes the `messageId`.

### Client messages

Messages with `role: 'system'` are local notices such as session expiry or upload progress. Their `kind` is `text`, `info`, `warning`, `error` or `success`, and they can include a `header` and `actions`.

<Canvas of={AiMessageThreadStories.WithClientMessages} />

### Empty state

When there are no messages, an empty state is shown. Customize it with the `empty-state-icon`, `empty-state-heading`, `empty-state-message` and `empty-state-actions` slots.
