A floating action button with a gradient border that opens an AI assistant. It shows the AI icon by default and can expand to include a text label.

<Canvas of={AiFabStories.Demo} />

## Usage

```html
<forge-ai-fab label="Open support assistant"></forge-ai-fab>

<forge-ai-fab extended>Ask AI</forge-ai-fab>
```

Set `extended` to show the default slot content next to the icon. Use the `icon` slot to replace the default AI icon.

### Branding

Override the `--forge-ai-fab-background`, `--forge-ai-fab-text-color` and `--forge-ai-fab-outline-color` custom properties to match your brand.
