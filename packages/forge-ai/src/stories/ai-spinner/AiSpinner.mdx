An indeterminate circular progress indicator. Use it to show that something is loading when you don't know how long it will take.

<Canvas of={AiSpinnerStories.Demo} />

## Usage

```html
<forge-ai-spinner size="small"></forge-ai-spinner>
```

Choose a `size` of `extra-small`, `small`, `medium` (default), or `large` to match the surrounding content.

<Canvas of={AiSpinnerStories.ExtraSmall} />

The spinner is purely visual and does not announce itself to assistive technology. Wrap it in an element with `role="status"` and a label when the loading state needs to be communicated.
