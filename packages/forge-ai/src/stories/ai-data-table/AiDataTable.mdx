Renders tabular data returned by an agent tool, with filtering, pagination and CSV download. Use it as the renderer for a tool that returns a table.

Import `@tylertech/forge-ai/tools`, then set `toolCall` on `forge-ai-tool-data-table`. `toolCall.args` holds the `title`, `headers`, `rows` and an optional `maxNumberOfRows` (default 10).

<Canvas of={AiDataTableStories.Demo} />

A filter input appears with more than 5 rows, and a paginator appears when the rows exceed `maxNumberOfRows`.
