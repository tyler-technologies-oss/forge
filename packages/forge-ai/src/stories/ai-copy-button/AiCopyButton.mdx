An icon button that copies a piece of text to the clipboard. Use it next to content users are likely to reuse, such as a code snippet or a generated answer.

<Canvas of={AiCopyButtonStories.Demo} />

## Usage

```html
<forge-ai-copy-button value="npm install @tylertech/forge-ai"></forge-ai-copy-button>
```

Clicking copies the `value` text. The icon switches to a check mark and the tooltip reads "Copied!" for 3 seconds, during which further clicks are ignored. If `value` is empty, or the button is disabled, clicking does nothing. The component does not fire events.
