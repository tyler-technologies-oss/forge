An inline text field with cancel and save buttons for renaming a conversation. [`forge-ai-conversations-panel`](?path=/docs/components-conversations-conversations-panel--docs) and [`forge-ai-threads-search`](?path=/docs/components-conversations-threads-search--docs) show it in place of a thread's row while it is being renamed. Use it directly only when building your own conversation list.

<Canvas of={AiEditThreadStories.Demo} />

## Usage

Set `thread` to the conversation being renamed and `value` to the text to start with. The input is focused and its text selected as soon as it renders.

```html
<forge-ai-edit-thread id="editor"></forge-ai-edit-thread>
```

```js
editor.thread = thread;
editor.value = thread.title;
editor.addEventListener('forge-ai-edit-thread-save', e => rename(e.detail.id, e.detail.newTitle));
editor.addEventListener('forge-ai-edit-thread-cancel', () => editor.remove());
```

- `forge-ai-edit-thread-save` fires on Enter or the save button, with the thread `id`, `oldTitle` and the trimmed `newTitle`. The component does not remove itself, so swap it out in your handler.
- `forge-ai-edit-thread-cancel` fires on Escape, the cancel button, or when focus leaves the field. It also fires on save if the new title is empty or unchanged.
