A searchable list of past conversations with an optional back button and "New chat" button. Use it for a chat history view. It renders the `threads` you give it and reports user intent through events, so your app owns loading and persistence.

<Canvas of={AiThreadsSearchStories.Demo} />

## Search

By default the list filters `threads` by title as the user types. To search elsewhere (for example on a server), cancel `forge-ai-threads-search-query` with `preventDefault()` and pass results to `setResults` in the event detail.

<Canvas of={AiThreadsSearchStories.WithAsyncSearch} />

```ts
threadsSearch.addEventListener('forge-ai-threads-search-query', evt => {
  evt.preventDefault();
  const { query, setResults } = evt.detail;
  fetchThreads(query).then(setResults);
});
```

## Paging

Set `total-chats` to the full count to enable infinite scroll, and append more with `appendResults` from the `forge-ai-threads-search-load-more` event.

<Canvas of={AiThreadsSearchStories.WithInfiniteScroll} />

## Renaming and deleting

Set `show-thread-rename` and `show-thread-delete` to show a per-thread menu. The rename and delete events are cancelable. Cancel one to handle the change yourself, then call `onSuccess()` or `onError()` from the event detail. Cancel `forge-ai-threads-search-delete-confirm` to show your own confirmation, then call `confirmThreadDelete(thread)` once accepted.

<Canvas of={AiThreadsSearchStories.WithRenameAndDelete} />

## Errors

Set `error-message` when a load fails. It shows a retry banner, or a compact line above or below the list if threads are already loaded. Clear it once the retry succeeds.
