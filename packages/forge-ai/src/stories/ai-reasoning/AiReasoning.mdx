A collapsible container for showing a model's reasoning as it streams in. Pair it with a `forge-ai-reasoning-header` in the `header` slot and add one `forge-ai-reasoning-content` per reasoning step. Each step types itself out when added.

<Canvas of={AiReasoningStories.Demo} />

The header's toggle event updates the container's `expanded` state automatically.

```html
<forge-ai-reasoning expanded>
  <forge-ai-reasoning-header slot="header" expanded reasoning>
    <span slot="reasoning-title">Thinking...</span>
    <span slot="title">Reasoning</span>
  </forge-ai-reasoning-header>
  <forge-ai-reasoning-content>Analyzing the problem...</forge-ai-reasoning-content>
</forge-ai-reasoning>
```

Append steps as they arrive:

```ts
const step = document.createElement('forge-ai-reasoning-content');
step.textContent = text;
reasoning.appendChild(step);
```

Set `reasoning` on the header while steps are streaming, then clear it when done.

## Header

`forge-ai-reasoning-header` is the clickable header that toggles the section. Put it in the `header` slot. While `reasoning` is set it shows the `reasoning-title` slot; otherwise it shows the `title` slot. It fires `forge-ai-reasoning-header-toggle` when the user expands or collapses it, with `detail.expanded`. The parent `forge-ai-reasoning` listens for it automatically.

```ts
header.addEventListener('forge-ai-reasoning-header-toggle', evt => {
  console.log(evt.detail.expanded);
});
```
