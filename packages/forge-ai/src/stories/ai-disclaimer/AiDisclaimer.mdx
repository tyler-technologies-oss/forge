A panel for terms of service, privacy notices, or other disclosures that the user must accept before continuing. It shows scrollable content with an optional icon and a pinned footer with Agree and Disagree buttons.

<Canvas of={AiDisclaimerStories.Demo} />

## Usage

Place the disclosure content in the default slot and handle the agree and disagree events. It works well inside a dialog or sidebar to gate access to an assistant.

```html
<forge-ai-disclaimer>
  <svg slot="icon" viewBox="0 0 24 24"><!-- icon path --></svg>
  <h2>Terms of Service</h2>
  <p>By using this AI assistant, you agree to our terms...</p>
</forge-ai-disclaimer>
```

```js
const disclaimer = document.querySelector('forge-ai-disclaimer');
disclaimer.addEventListener('forge-ai-disclaimer-agree', () => {
  /* grant access */
});
disclaimer.addEventListener('forge-ai-disclaimer-disagree', () => {
  /* dismiss */
});
```

### Custom button text

Use the `agree-button-text` and `disagree-button-text` slots to replace the default labels.
