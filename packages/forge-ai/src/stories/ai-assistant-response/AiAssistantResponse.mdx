Renders one complete assistant turn: its text, any tool calls the assistant made, and a toolbar with copy, resend and optional feedback buttons. Use it when you build your own message list; [`forge-ai-message-thread`](?path=/docs/components-chat-message-thread--docs) uses it for assistant turns.

<Canvas of={AiAssistantResponseStories.Demo} />

## Usage

Set `response` to an `AssistantResponse`. Its `children` are text chunks and tool calls, rendered in order, and `status` is `streaming`, `complete` or `error`. Text is rendered as markdown.

```ts
element.response = {
  id: 'response-1',
  status: 'complete',
  timestamp: Date.now(),
  children: [{ type: 'text', messageId: 'message-1', status: 'complete', content: 'Hello!' }]
};
```

The toolbar appears once the response is `complete` and contains text. Set `enable-reactions` to add thumbs up and thumbs down buttons. A response that is not complete and has no content yet renders nothing, unless `show-thinking` is set.

### Tool calls

Pass `tools` as a `Map` of tool name to tool definition. Consecutive tool calls are summarized in a [tool call indicator](?path=/docs/components-tools-reasoning-tool-call-indicator--docs), and a call whose definition has a `renderer` also renders its result with [`forge-ai-tool-call`](?path=/docs/components-tools-reasoning-tool-call--docs). Calls without a renderer only appear in the indicator.

<Canvas of={AiAssistantResponseStories.WithToolCall} />

### Thinking

Set `show-thinking` to show a thinking indicator while the response is in progress, for example before the first text arrives or between steps. Set `isThinking` on the response to keep the indicator visible between steps while earlier text is still streaming.

<Canvas of={AiAssistantResponseStories.Thinking} />

### Events

The toolbar events carry the `responseId`, and the thumbs events also carry the optional `feedback` text. They do not bubble, so listen on the element itself.
