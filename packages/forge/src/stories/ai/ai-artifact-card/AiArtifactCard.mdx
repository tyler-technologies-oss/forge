A compact, clickable card for something an agent produced, such as a query result, report or generated document. Use it in a conversation to let users open the artifact.

The card is presentational. Activating it emits `forge-ai-artifact-card-open` with the card's `assetId`, and your code decides what opens.

<Canvas of={AiArtifactCardStories.Demo} />

## Usage

- `title-text` and `subtitle-text` each truncate to one line.
- Slot an `icon` to replace the default artifact glyph.
- For several results at once, place cards in a `forge-ai-artifact-card-group`.

## Active state

Set `active` on the card for the artifact currently being viewed. It gets an accent border and ring, and its arrow hides since there is nothing left to open. You control when a card is active.

<Canvas of={AiArtifactCardStories.Active} />

## Collapsing on a second activation

An active card still emits `forge-ai-artifact-card-open`, so you can treat a second activation as "collapse". Set `action-label` so assistive technology hears what activation now does, and slot an `action-icon`, which stays visible while active.

<Canvas of={AiArtifactCardStories.CollapsibleAction} />

## Distinguishing card types

When you render more than one kind of artifact, lead the subtitle with the type ("Report · 4 charts"). The icon is decorative, so the subtitle is the only place the type reaches screen reader users.

## Accessibility

- The whole card is one native `<button>`. Its accessible name is the card text, with `action-label` appended when set.
- The icon and action glyph are `aria-hidden`.
- The active card sets `aria-current="true"`; visually it also gets the outer ring, not just a color change.
