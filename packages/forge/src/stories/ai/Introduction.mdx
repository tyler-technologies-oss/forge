# Forge AI

`@tylertech/forge-ai` is a library of Web Components for building AI chat interfaces: messages, prompts, tool-call indicators, dialogs, sidebars, canvases, and the small utilities they need.

The components are UI building blocks. They do not manage conversation state or talk to a model, so you bring your own chat logic and layout and compose the pieces you need. Each page in this section documents one component using static data.

## Installation

```bash
npm install @tylertech/forge-ai @tylertech/forge
```

## Registering components

Import each component you use. Every component is a subpath of the package, and importing it registers the element with the browser.

```ts
import '@tylertech/forge-ai/ai-chat-interface';
import '@tylertech/forge-ai/ai-prompt';
```

```html
<forge-ai-prompt placeholder="Ask a question..."></forge-ai-prompt>
```

Shared data shapes (messages, tools, threads, agents, files) are exported from `@tylertech/forge-ai/types`:

```ts
import type { MessageItem, Thread, Agent } from '@tylertech/forge-ai/types';
```

Markdown rendering and other helpers are exported from `@tylertech/forge-ai/utils`, and the tool renderer elements (data table, paginator, steps) from `@tylertech/forge-ai/tools`.

## Styling

The components style themselves with Forge design tokens. For the correct fonts, colors, and spacing, load the Forge global stylesheet and theme in your application. See [Getting Started](?path=/docs/getting-started-installation--docs) for details.
