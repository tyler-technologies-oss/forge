Renders the custom UI for a tool call. Give it a `toolCall` and the `toolDefinition` that describes the tool, and it displays that definition's `renderer`. Use it to show the result of a tool, such as a table or a map, in your own chat interface.

<Canvas of={AiToolCallStories.Demo} />

It is exported from `@tylertech/forge-ai/ai-tool-call`.

## Usage

```ts
import '@tylertech/forge-ai/ai-tool-call';

const element = document.querySelector('forge-ai-tool-call');
element.toolDefinition = definition;
element.toolCall = toolCall;
```

Nothing is rendered when the tool definition has no `renderer`, or until the call is ready to show. A call is ready once its `status` is `complete`. Set `renderOnStart: true` on the definition to render while the call is still `parsing` or `executing`.

## Custom renderers

A tool's `renderer` is either a `render` function or the tag name of a custom element. Use `createToolRenderer` to build one.

**Function:** return an element or fragment for the given tool call. It runs again when the `toolCall` or `toolDefinition` changes.

```ts
import { createToolRenderer } from '@tylertech/forge-ai/ai-tool-call';

const getCurrentWeather = {
  name: 'getCurrentWeather',
  renderer: createToolRenderer({
    render: toolCall => {
      const element = document.createElement('p');
      element.textContent = `${toolCall.args.location}: ${toolCall.result?.condition}`;
      return element;
    }
  })
};
```

**Element:** register a custom element and pass its tag. The tool call is assigned to its `toolCall` property, and the same element is updated in place as the call changes.

```ts
const getCurrentWeather = {
  name: 'getCurrentWeather',
  renderer: createToolRenderer({ elementTag: 'my-weather-card' })
};
```

Type the element with `IToolRenderer` from `@tylertech/forge-ai/types` to declare the `toolCall` property.
