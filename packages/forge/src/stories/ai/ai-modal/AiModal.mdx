A simple modal dialog built on the native `<dialog>` element. It has no default content, so you provide everything through the default slot.

<Canvas of={AiModalStories.Demo} />

## Usage

Open and close the modal with the `open` property or attribute, or the `show()` and `close()` methods.

```html
<forge-ai-modal label="Settings">
  <h3>Title</h3>
  <p>Content</p>
</forge-ai-modal>
```

The modal closes on Escape or a backdrop click. The `forge-ai-modal-close` event includes a `reason` of `backdrop`, `escape` or `programmatic`.

### Sizing

By default the modal goes fullscreen on viewports 768px wide or narrower. Set `size-strategy="fixed"` to keep the size on all viewports, or set `fullscreen` explicitly. In non-fullscreen mode use `--forge-ai-modal-width` and `--forge-ai-modal-height` to change the size.

## Accessibility

Focus management, Escape handling and screen reader support come from the native `<dialog>` element. Set `label` (default: `"AI Assistant"`) to describe the modal content; it is applied as the dialog's `aria-label`.
