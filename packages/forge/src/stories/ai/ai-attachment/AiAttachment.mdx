Shows a file attached to a message: its name and size, with an optional remove button. Use it for files a user has added to a prompt.

Set `filename` and `size` (in bytes). Add `removable` to show a remove button, which emits `forge-ai-attachment-remove` with the `filename`.

<Canvas of={AiAttachmentStories.Demo} />

## Uploading

Set `uploading` to dim the attachment and show a spinner. Add `progress` (0 to 100) for a progress bar. While uploading, the remove button reads as a cancel action.

## Accessibility

- The attachment is a `role="group"` labeled with the filename.
- The remove button's label includes the filename ("Remove report.pdf", or "Cancel upload of report.pdf" while uploading).
- The upload progress bar has `role="progressbar"` with `aria-valuenow`.
