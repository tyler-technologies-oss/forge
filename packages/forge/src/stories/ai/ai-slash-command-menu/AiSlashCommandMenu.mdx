A popup list of slash commands, grouped by category, shown above an input. [`forge-ai-prompt`](?path=/docs/ai-components-chat-prompt--docs) already uses it when you set `slashCommands`, so you only need this component to build a custom input.

## Usage

The menu does not watch any input. Set `anchor` to the element to position against, set `open`, and pass the text after the `/` as `filter-query`. Forward `keydown` events from your input to `handleKeyDown()`, which handles arrow keys, Home, End, Enter and Escape and returns `true` when it used the key.

```ts
menu.commands = [{ id: 'clear', name: 'Clear conversation', group: 'Conversation' }];
menu.anchor = input;
input.addEventListener('keydown', evt => menu.handleKeyDown(evt));
menu.addEventListener('forge-ai-slash-command-menu-select', evt => run(evt.detail.command));
menu.addEventListener('forge-ai-slash-command-menu-close', () => (menu.open = false));
```

- `forge-ai-slash-command-menu-select` fires with the `command` and its `index` in the filtered list. The menu does not close itself, so set `open` to `false`.
- `forge-ai-slash-command-menu-close` fires when the user presses Escape (through `handleKeyDown()`) or clicks the close button. The menu does not close itself here either.
- The menu is as wide as `widthReference`, falling back to the `anchor`, or 300px if neither is set.

### Filtering

Commands are matched by name, ignoring case. Commands stay grouped by their `group`, and the menu shows "No commands found" when nothing matches.
