Three animated dots that show the assistant is working. Show it between sending a prompt and the first streamed content.

<Canvas of={AiThinkingIndicatorStories.Demo} />

Set `show-text` to add a status message that cycles through words like "Thinking..." and "Analyzing...". Use `initial-delay` to wait before the first message appears and `cycle-interval` to change how often it rotates (milliseconds).

The animation is simplified when the user prefers reduced motion.
