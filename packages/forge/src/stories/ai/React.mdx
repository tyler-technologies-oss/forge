# React

`@tylertech/forge-ai` ships typings for using its elements directly in **React 19** JSX. There is no wrapper package: React 19 supports custom elements natively, so you render `<forge-ai-prompt>` and friends as-is.

> **React 19 is required.** React 18 stringifies object props, does not attach `on<event>` props as listeners, and renders `className` literally instead of `class`.

## Setup

Add the typings to `compilerOptions.types` in your `tsconfig.json`:

```json
{
  "compilerOptions": {
    "types": ["@tylertech/forge-ai/jsx"]
  }
}
```

Setting `types` turns off automatic inclusion of other `@types/*` packages, so list the ones you need too (for example `"types": ["node", "@tylertech/forge-ai/jsx"]`).

## Registering elements

The typings do not load the components. Register each element with a side-effect import:

```tsx
import '@tylertech/forge-ai/ai-prompt';

export function Chat() {
  return <forge-ai-prompt placeholder="Ask a question..." />;
}
```

## Properties

Use the camelCase property names. They are type-checked and work for every value type (arrays, objects, booleans, strings):

```tsx
import type { MessageItem } from '@tylertech/forge-ai/types';

const items: MessageItem[] = [];

<forge-ai-message-thread messageItems={items} enableReactions />
```

TypeScript does not check hyphenated JSX attribute names, so a misspelled kebab-case attribute compiles silently. Prefer camelCase.

Booleans that default to `true` (for example `cancelOnEscape` on `forge-ai-prompt`) cannot be turned off with an attribute. Pass `false` as a property: `<forge-ai-prompt cancelOnEscape={false} />`.

## Events

Event props are `on` plus the event name exactly as dispatched, with no case conversion:

```tsx
<forge-ai-prompt onforge-ai-prompt-send={event => console.log(event.detail.value)} />
```

`onForgeAiPromptSend` does not work. As with attributes, a typo in a hyphenated event name is not caught by TypeScript, so copy event names from the component API tables.

## Refs

`ref` is typed to the element class, which gives you its full public API:

```tsx
import { useRef } from 'react';
import type { AiPromptComponent } from '@tylertech/forge-ai/ai-prompt';

const prompt = useRef<AiPromptComponent>(null);

<forge-ai-prompt ref={prompt} />;

prompt.current?.focus();
```

## Slots

Use the standard `slot` attribute on children:

```tsx
<forge-ai-prompt>
  <forge-icon-button slot="actions" />
</forge-ai-prompt>
```
