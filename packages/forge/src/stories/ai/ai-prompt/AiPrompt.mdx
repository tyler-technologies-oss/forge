A text input for sending messages to an AI assistant. It has a send button, optional action slots, slash commands, context chips, and up and down arrow history for recalling previous messages.

<Canvas of={AiPromptStories.Demo} />

## Usage

Listen for `forge-ai-prompt-send` to receive the message. The input clears after sending, unless you call `preventDefault()` on the event.

```html
<forge-ai-prompt placeholder="Ask a question..."></forge-ai-prompt>
```

```js
prompt.addEventListener('forge-ai-prompt-send', e => {
  console.log(e.detail.value);
});
```

While a response is generating, set `running` to show a stop button; `forge-ai-prompt-stop` fires when it is clicked.

### Layout

The `variant` is `stacked` (default), with actions in a row below the input, or `inline`, with actions beside the input.

### Action slots

- `actions-start`: start of the actions row in stacked layout, or before the input in inline layout
- `actions-end`: just before the send button

Use them for controls such as file pickers, voice input, or `forge-button` options.

### Slash commands and context

Set `slashCommands` to show a command menu when the user types `/`, and handle `forge-ai-prompt-command`. Set `contextItems` to show removable chips above the input and handle `forge-ai-prompt-context-remove`.
