A compact previous and next paginator with a "page of total" label. Use it to page through results, for example in a table tool result. It is exported from `@tylertech/forge-ai/tools`.

<Canvas of={AiPaginatorStories.Demo} />

## Usage

The paginator does not change pages itself. Handle `forge-ai-paginator-page-change` and update `current-page`; the event detail has `currentPage` (the new page) and `previousPage`.

```js
paginator.addEventListener('forge-ai-paginator-page-change', e => {
  paginator.currentPage = e.detail.currentPage;
});
```

```html
<forge-ai-paginator current-page="1" total-pages="5"></forge-ai-paginator>
```
