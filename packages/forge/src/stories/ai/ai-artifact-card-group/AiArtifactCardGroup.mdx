The AI Artifact Card Group presents several `forge-ai-artifact-card` elements as one list — for example, when an
agent returns more than one result for a single request. Past a set count, the extra cards collapse behind a toggle.

<Canvas of={AiArtifactCardGroupStories.Demo} />

## Features

- **One container**: the group draws the border, corners, and dividers; cards inside it switch to a row style on
  their own, with no extra attributes
- **Collapsing**: cards past `visible-count` (3 by default) are hidden until the user expands the list
- **Cards keep their API**: each row still emits `forge-ai-artifact-card-open`, so open handling is the same as for
  a single card
- **Translatable toggle**: both toggle labels are properties; `{count}` in `show-more-text` becomes the number of
  collapsed cards
- **Respects `hidden`**: a card you hide yourself stays hidden and is not counted; collapsing uses its own marker

## When every card fits

With `visible-count` cards or fewer, no toggle renders.

## Accessibility

- The group is exposed as a list and each card as a list item, so screen readers announce the number of visible
  results; the toggle's label carries the count of collapsed ones
- The toggle is a native button with `aria-expanded`
- Collapsed cards are removed from layout, so they leave the tab order and the accessibility tree
- Focus stays on the toggle after expanding or collapsing
