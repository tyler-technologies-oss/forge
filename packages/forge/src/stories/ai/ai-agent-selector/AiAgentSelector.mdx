A dropdown for switching between AI agents. Use it when users can choose which agent handles their conversation.

Pass the available `agents` (`{ id, name, description? }`) and the current `selectedAgentId`. The first menu option is always the default (unselected) agent, labeled with `titleText`. With no `agents`, the component shows `titleText` as static text. A search filter appears when there are more than 5 agents.

<Canvas of={AiAgentSelectorStories.Demo} />

## Usage

The selector is controlled: it emits `forge-ai-agent-selector-change` but does not update its own selection. Set `selectedAgentId` in response. `agent` is `undefined` when the default option is chosen.

```ts
selector.addEventListener('forge-ai-agent-selector-change', e => {
  const { agent, previousAgentId } = e.detail;
  selector.selectedAgentId = agent?.id;
});
```

## Accessibility

The selector supports full keyboard navigation:

- **Enter / Space** - Open dropdown or select focused item
- **Escape** - Close dropdown and return focus to trigger
- **Arrow Down / Up** - Navigate through agent options
- **Home** - Jump to default option
- **End** - Jump to last agent
