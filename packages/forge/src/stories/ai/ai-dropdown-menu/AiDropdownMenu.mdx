A button that opens a menu of choices, such as a model picker or an actions menu. Items can act as plain actions, a single (radio) selection, or a multiple (checkbox) selection, and can be grouped or nested in submenus.

<Canvas of={AiDropdownMenuStories.Demo} />

## Usage

Add `forge-ai-dropdown-menu-item` elements to the default slot and set `selection-mode` to `none` (default), `single` or `multi`. The `forge-ai-dropdown-menu-change` event reports the new `value` and the selected item(s) for the active mode.

```html
<forge-ai-dropdown-menu selection-mode="single">
  <span slot="trigger-content">Select model</span>
  <forge-ai-dropdown-menu-item value="small">Small</forge-ai-dropdown-menu-item>
  <forge-ai-dropdown-menu-item value="large">Large</forge-ai-dropdown-menu-item>
</forge-ai-dropdown-menu>
```

The trigger can be a text `button` (default), an `icon-button`, or an `icon-button-squared`. Use `density` to change its size.

### Groups and separators

Organize items with `forge-ai-dropdown-menu-item-group` (label via the `label` slot) and `forge-ai-dropdown-menu-separator`.

<Canvas of={AiDropdownMenuStories.WithGroups} />

### Nested menus

Place a `forge-ai-dropdown-menu` in an item's `submenu` slot. Use the item's `submenu-trigger` (`hover`, `click` or `both`) to choose how it opens.

<Canvas of={AiDropdownMenuStories.WithNestedMenus} />

## Keyboard

- Arrow Up and Down move between items
- Enter and Space select the focused item
- Arrow Right and Left open and close submenus
- Home and End jump to the first and last item
- Escape closes the menu, and it also closes when focus leaves

## Accessibility

Menu roles follow the selection mode (`menuitem`, `menuitemradio`, `menuitemcheckbox`). For icon-only triggers, set `trigger-label` so the button has an accessible name.
