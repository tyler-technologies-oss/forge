A compact summary of the tool calls an assistant made while answering. Collapsed, it reads "Running tools..." or "Used N tools · Xs". Expanded, it lists each call with a status marker. Use it to show tool activity without cluttering the conversation.

<Canvas of={AiToolCallIndicatorStories.Demo} />

Pass `toolCalls`, plus an optional `tools` map keyed by tool name so each row shows the tool's `displayName` instead of its raw name.

## Status

The indicator renders whatever `status` each tool call has. It shows the running summary while any call is not `complete` or `error`. A call whose tool renders its own UI early (`renderOnStart`) counts as settled.

<Canvas of={AiToolCallIndicatorStories.Running} />

A failed call is a `status: 'error'` entry.

<Canvas of={AiToolCallIndicatorStories.FailedToolCall} />

## Debug mode

Set `debug-mode` to let users expand each call and see its input, output, or error.
