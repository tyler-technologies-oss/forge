## Key strings

The `keys` property accepts an array of strings representing each non-modifier key to display. The
attribute equivalent accepts a space-separated string of keys. Some keys require special handling to
show to correct name or glyph.

| Key string          | Output                                 |
|---------------------|----------------------------------------|
| Enter               | `Enter` (`Return` on Apple platforms)  |
| ArrowUp             | `↑`                                    |
| ArrowDown           | `↓`                                    |
| ArrowLeft           | `←`                                    |
| ArrowRight          | `→`                                    |
| Escape              | `Esc`                                  |
| Pagedown            | `Page Down`                            |
| Pageup              | `Page Up`                              |
| Printscreen         | `Print Screen`                         |
| Scrolllock          | `Scroll Lock`                          |

All other keys are displayed as provided but transformed to title case.

## Modifier keys

Modifer keys are displayed using platform-appropriate glyphs.

| Modifier key | Windows / Linux | Apple |
|--------------|----------------|-------|
| Control      | `Ctrl`         | `⌃`   |
| Shift        | `⇧`            | `⇧`   |
| Alt          | `Alt`          | `⌥`   |
| Meta         | `Meta`         | `⌘`   |

## Accessibility

  representing keyboard input.
