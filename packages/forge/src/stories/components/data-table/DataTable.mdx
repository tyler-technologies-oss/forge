The Data Table component provides a powerful and flexible way to display and interact with tabular data.
It supports features such as sorting, filtering, column resizing and reordering, row selection, and more.

## Features

- **Sorting**: Click on column headers to sort data
- **Filtering**: Apply filters to columns to narrow down displayed data
- **Resizing**: Adjust column widths by dragging column dividers
- **Reordering**: Drag and drop columns to rearrange them
- **Row Selection**: Select single or multiple rows
- **Row Clicking**: Respond to row click events
- **Toolbar**: Show and hide columns, export to CSV, print, and toggle filtering or row selection
- **Column Visibility**: Right-click headers to open a column menu or control visibility programmatically
- **Cell Templates**: Render badges, links, meters, ratings, action buttons, inputs, or your own content in a cell
- **Aggregation**: Show sums, averages, counts, ranges, or custom results in a footer
- **Column Renaming**: Let users rename column headers
- **Formatters**: Format numbers, currency, and dates, or transform values with a function
- **Styling Options**: Apply various styling options like striped rows, hover effects, and more
- **Virtualization**: Efficiently handle large datasets with row virtualization for improved performance
- **Fixed Headers**: Keep column headers visible while scrolling through large datasets

## Toolbar

Add a `forge-data-table-toolbar` above the table and connect it by setting `table` to the id of the data table.
The `features` attribute picks the icon buttons to show: `columns` (show and hide columns), `export` (download as CSV),
`filter` (toggle column filters), `print`, and `select` (toggle row selection). Use the `title` slot for the table's title.

## Aggregation

Set a column's `aggregate` to show a calculated value in the footer. The built-in aggregations are `sum`, `mean`, `median`, `min`,
`max`, `extent`, `count`, `uniqueCount`, `unique`, `first` and `last`. The aggregates are calculated over the filtered rows.
