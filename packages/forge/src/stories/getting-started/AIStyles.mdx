# AI Styles

Forge provides an optional stylesheet that gives components a distinctive gradient treatment. Use it to visually mark parts of your UI that are generated by,
or interact with, AI, such as a prompt field or the toggle that enables an AI feature.

The styles are opt-in. Nothing changes until you load the stylesheet **and** add the `forge-ai` class to a component.

## Adding the stylesheet

The AI styles ship as a standalone `forge-ai.css` stylesheet. It is not included in `forge.css`, so load it in addition to your usual Forge setup.

### NPM

Import the stylesheet from the `@tylertech/forge` package in your application's entry point:

```javascript
import '@tylertech/forge/dist/forge-ai.css';
```

Or from a stylesheet:

```css
@import '@tylertech/forge/dist/forge-ai.css';
```

```scss
@use '@tylertech/forge/dist/forge-ai.css';
```

> Load the stylesheet globally. If your framework scopes component styles, such as Angular's view encapsulation, add it to your global styles instead
> of a component's stylesheet.

### CDN

```html
<link rel="stylesheet" href="https://cdn.forge.tylertech.com/v1/libs/@tylertech/forge@<version>/forge-ai.css" />
```

> Replace `<version>` with the version of Tyler Forge you want to use.

## Using the class

Add the `forge-ai` class to a supported Forge component to apply the AI styles to it:

```html
<forge-text-field class="forge-ai">
  <label slot="label" for="prompt">Prompt</label>
  <input type="text" id="prompt" />
</forge-text-field>
```

The class goes on the Forge component itself rather than a wrapper element. Because it is a regular CSS class, you can add and remove it as the state of your
UI changes, using whatever class binding your framework provides:

```javascript
field.classList.toggle('forge-ai', isAiAssisted);
```

The styles are purely visual. Component behavior, attributes, and accessibility are unchanged.

## Supported components

| Component                                                                        | Where to add the class                                                  | What it styles                                                       |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `forge-field`, `forge-text-field`, `forge-select`, `forge-chip-field`            | The component                                                           | Gradient outline, glow, and background                               |
| `forge-autocomplete`, `forge-date-picker`, `forge-date-range-picker`, `forge-time-picker` | The picker, which styles the field nested directly inside of it | Gradient outline, glow, and background of the nested field           |
| `forge-checkbox`                                                                 | The component                                                           | Gradient checked state                                               |
| `forge-radio`, `forge-radio-group`                                               | Each radio, or the group to style every radio within it                 | Gradient selected state                                              |
| `forge-switch`                                                                   | The component                                                           | Gradient track when on                                               |

### Fields

Fields get a gradient outline with a soft glow, and a gradient background that follows your light or dark theme. They keep working with their usual attributes,
so the AI styles can be combined with any `variant`. The `plain` variant has no outline or background of its own, so it only gets a gradient underline.

<Canvas of={AIStylesStories.Variants} />

Invalid fields keep their standard error outline instead of the gradient outline, and disabled fields are dimmed like any other disabled field.

### Autocomplete and pickers

The autocomplete and date and time pickers wrap a `forge-text-field`. Add the class to the picker and it styles the text field inside of it.

```html
<forge-date-picker class="forge-ai">
  <forge-text-field>
    <label for="date">Date</label>
    <input type="text" id="date" autocomplete="off" />
  </forge-text-field>
</forge-date-picker>
```

## Customization

The gradient colors and field dimensions are controlled by CSS custom properties. Set them on a `forge-ai` component, or on any ancestor to change several at once.

| Property                     | Default                                                | Description                                                                                 |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `--forge-ai-gradient-start`  | `#e9c2ec`                                              | The first color of the gradient. Used by every supported component.                         |
| `--forge-ai-gradient-end`    | `#cbcdff`                                              | The last color of the gradient. Used by every supported component.                          |
| `--forge-ai-background`      | The gradient colors blended with `--forge-theme-surface` | The background of fields. Accepts any CSS `background` value, such as a gradient or color. |
| `--forge-ai-border-width`    | `var(--forge-border-thin)`                             | The width of a field's gradient outline, or the plain variant's underline.                  |
| `--forge-ai-glow-width`      | `var(--forge-border-thick)`                            | The width of the glow around a field's outline.                                             |

```css
.my-ai-section {
  --forge-ai-gradient-start: #ffd8a8;
  --forge-ai-gradient-end: #a5d8ff;
}
```

<Canvas of={AIStylesStories.Customization} />

The stylesheet is declared in a `forge-ai` [cascade layer](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer), so any of your own unlayered CSS takes
precedence over it regardless of specificity or the order the stylesheets are loaded. This makes it safe to override the Forge component tokens that the AI styles
set, such as `--forge-field-background`, for a specific element.
