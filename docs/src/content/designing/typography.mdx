Forge uses one font, Roboto, and a fixed set of type styles. Every piece of text in a design should use one of these styles rather than a custom size or weight. The full list of classes and how to load them is on the [developer typography](/developing/typography/) page, and the token values are on the [typography tokens](/tokens/typography/) page.

## The scale

Each style family is numbered from smallest to largest. `heading1` is the smallest heading and `heading8` the largest.

| Family       | Range                       | Use                                                  |
| ------------ | --------------------------- | ---------------------------------------------------- |
| `display`    | `display1`–`display8`       | Large, prominent text, like a hero or an empty state |
| `heading`    | `heading1`–`heading8`       | Page, container, and section titles                  |
| `subheading` | `subheading1`–`subheading8` | Secondary titles that sit under a heading            |
| `body`       | `body1`–`body4`             | Paragraphs and general content                       |
| `label`      | `label1`–`label3`           | Field labels, group labels, and small metadata       |

`body2` is the page default. It's applied to `<body>` when the typography stylesheet loads. Use `body1` for dense or secondary content, like table cells or supporting text.

## Hierarchy

These are the styles to reach for in a Forge application. They match the [layout](/designing/layout/) patterns.

| Element                           | Style                |
| --------------------------------- | -------------------- |
| Page title (body header)          | `heading4`           |
| Card, dialog, and drawer titles   | `heading3`           |
| Section headings inside a surface | `heading2`           |
| Body text                         | `body2`              |
| Dense or secondary text           | `body1`              |
| Group labels and metadata         | `label1` or `label2` |

Container titles are one step smaller than the page title, so a card never competes with the page around it. When a container needs smaller headings, go smaller, not larger.

## Semantic level vs visual style

Pick the HTML heading level from the document outline, and the visual style from the hierarchy above. The two are independent. In an app layout, the app title in the app bar is the `h1`, so the page title is an `h2` styled `heading4`, and card titles are usually `h3` styled `heading3`.

## Emphasis

Change emphasis with text color, not with size or weight. Use `text-high` for primary content, `text-medium` for descriptions and secondary text, and `text-low` for supporting text. See the [color system](/designing/color/#text) for the full set.
