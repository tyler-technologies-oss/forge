## Usage

`forge-tab-bar` groups `forge-tab` children and tracks which one is active through `activeTab`/`activeTabName`, `vertical`, `clustered`, and `scrollButtons`. Pair each tab with a `forge-tab-panel` (matched by `for`) to show and hide its content. Use tabs for closely related content at the same level, inside a card, dialog, or side sheet, or as primary navigation when an app has fewer than five destinations; beyond that, use a <a href={`${import.meta.env.BASE_URL}components/drawer/usage/`}>drawer</a> instead.

## Named tabs

Track the active tab by name instead of index — set `activeTabName` on the tab bar, and name each tab to match:

```html
<forge-tab-bar active-tab-name="two">
  <forge-tab name="one">Tab one</forge-tab>
  <forge-tab name="two">Tab two</forge-tab>
</forge-tab-bar>
```

Read the active tab's name off the `forge-tab-bar-change` event's `detail.name`, rather than tracking index and looking it up yourself:

```js
tabBar.addEventListener("forge-tab-bar-change", (event) => {
  console.log("Active tab name:", event.detail.name);
});
```
