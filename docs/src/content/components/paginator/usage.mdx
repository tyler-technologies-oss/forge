## Usage

`forge-paginator` navigates a `total`-item collection through `pageIndex`, `pageSize`, `pageSizeOptions`, and `firstLast`/`first` jump buttons, plus an `alternative` compact layout. Pair it with a <a href={`${import.meta.env.BASE_URL}components/table/usage/`}>table</a> or <a href={`${import.meta.env.BASE_URL}components/list/usage/`}>list</a> whose data is sorted in a logical order, so a user can jump to a page or mentally orient within the set. For casual browsing or discovery, infinite scroll fits better than pagination.

## Basic usage

Set `total` to the full item count; the paginator computes page count from `pageSize`.
