## Usage

`forge-chip` represents an entity, filterable attribute, or action through its `type` — `choice`, `filter`, `action`, `input`, or `field` — plus `theme`, `selected`, and `dense`. Chips are interactive and appear dynamically as a group inside a `forge-chip-set`; reach for a <a href={`${import.meta.env.BASE_URL}components/button/usage/`}>button</a> instead for a persistent, primary call to action, or a <a href={`${import.meta.env.BASE_URL}components/badge/usage/`}>badge</a> instead for non-interactive status.

## Types

Set `type` to match the chip's role: `choice` for a single selection from a small set, `filter` for the same pattern applied to filtering content, `action` (the default) for a contextual action, `input` for a removable, user-entered value, and `field` for chips living inside a `forge-chip-field`.

## Choice and filter

Set `type="choice"` for a single selection from a small set, or `type="filter"` for the same pattern applied to filtering content — both share the same `selected` state.
