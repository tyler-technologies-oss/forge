## Usage

`forge-slider` selects a value — or, with `range`, a start and end value — along a bounded track through `min`, `max`, `step`, `tickmarks`, and `labeled`, and participates in form submission via `name`. Reserve it for a value that's fine to be approximate; when a user needs to enter a known, specific number, use a <a href={`${import.meta.env.BASE_URL}components/text-field/usage/`}>text field</a> instead.
