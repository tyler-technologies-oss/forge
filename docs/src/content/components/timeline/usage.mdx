## Usage

`forge-timeline` connects a series of `forge-timeline-item` children with a vertical line through their markers. Each item's main content goes in its default slot, with `start` and `end` slots on either side, a `marker` slot for the indicator, and a `detail` slot below for extra context. Use `forge-timeline-break` between items to visually separate non-sequential groups. Reach for a plain <a href={`${import.meta.env.BASE_URL}components/list/usage/`}>list</a> instead when order and time aren't meaningful to the content.

## Sidebar lines

An item's `sidebar` defaults to `auto`, which draws its connecting line above and below its marker, automatically omitting whichever side doesn't apply to the first or last item. Set `sidebar` to `start`, `end`, `both`, or `none` to control this manually — useful for implying items exist before or after what's actually rendered.

Put extra context for an item in its `detail` slot, below its main content. Wrap the detail in a `forge-card` when it needs visual grouping, like a summary with badges.

## Timestamps

Place a <a href={`${import.meta.env.BASE_URL}components/timestamp/usage/`}>timestamp</a> as a direct child of the timeline to show it as a date heading for the items below it. Inside an item, a timestamp renders inline with the content, and `separator` adds a dot between them. Put item timestamps in the `start` slot when they should line up across items.
