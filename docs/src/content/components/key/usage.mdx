## Usage

`forge-key` lays out one or more `forge-key-item` entries, each pairing a colored icon with a label (and an optional `value` slot), to explain what a color or series means in a chart or visualization. It's the standard companion to a <a href={`${import.meta.env.BASE_URL}components/meter/usage/`}>grouped meter</a>: label each meter in the group with a key item sharing its color, so the grouping is legible without relying on color alone.
