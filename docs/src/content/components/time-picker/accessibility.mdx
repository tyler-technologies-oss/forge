## Labeling

Add an `aria-label` to the `<input>` if you're not pairing it with a `<label for>` — the time picker doesn't infer one on its own.

## Automatic ARIA attributes

The component applies `aria-live`, `aria-atomic`, `aria-haspopup`, `aria-expanded`, `aria-owns`, and `aria-disabled` to the input for you, so you don't need to set those yourself.

## Keyboard interaction

Verify that a screen reader announces keyboard navigation through the suggestion dropdown as the user moves between options.
