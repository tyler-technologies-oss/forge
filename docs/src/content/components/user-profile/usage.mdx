## Overview

The user profile displays a user's authentication state in an application. Signed out, it shows a sign-in button. Signed in, it shows the user's avatar, which opens a popover with their name, email, profile links, an optional theme toggle, and a sign-out action. It's typically placed at the end of an <a href={`${import.meta.env.BASE_URL}components/app-bar/usage/`}>app bar</a>.

## Usage

`forge-user-profile` is signed in when `full-name` is set and signed out when it's empty. Set `full-name`, `email`, and `image-url` for the signed-in state; the avatar falls back to the user's initials when there's no image. Add `forge-profile-link` elements in the `link` slot for navigation like settings or account pages, each wrapping an `<a>` and an optional `icon`. Set `theme-toggle` to let users choose a light, dark, or system theme, and call `setTheme()` to change it from code. Handle `forge-user-profile-sign-in` and `forge-user-profile-sign-out` to run your authentication logic, and use the `sign-in-button-text`, `sign-out-button-text`, and `theme-toggle-*` slots to customize or localize text. Use `open` to control the popover. It's meant for the app bar's `end` slot; for other account menus, build one with a <a href={`${import.meta.env.BASE_URL}components/menu/usage/`}>menu</a> or <a href={`${import.meta.env.BASE_URL}components/popover/usage/`}>popover</a>.
