## Usage

`forge-timestamp` renders a `<time>` element from a `datetime` value, formatted through `format` (a CLDR date/time pattern), `locale`, and `separator`. Set `datetime` to a `Date`, a date-convertible string, or any value the native `<time>` element's `datetime` attribute accepts; that value drives both the accessible meaning and, for full dates, the automatic formatting. A dateless time, timezone offset, or duration value is used as-is for accessibility but isn't auto-formatted — pass custom content in the default slot for those cases. Use it anywhere a date or time needs consistent, localized formatting, including inside a <a href={`${import.meta.env.BASE_URL}components/timeline/usage/`}>timeline</a> item.

## Formatting

Set `format` to any valid CLDR date/time pattern to control how the timestamp displays.

```html
<!-- Hour and minute -->
<forge-timestamp datetime="2024-03-15T14:30:00" format="HH:mm"></forge-timestamp>

<!-- Day and month -->
<forge-timestamp datetime="2024-03-15T14:30:00" format="MMMM dd"></forge-timestamp>

<!-- With additional text -->
<forge-timestamp datetime="2024-03-15T14:30:00" format="'Today' • MMMM dd, yyyy"></forge-timestamp>
```

## Locale

Set `locale` to format the timestamp for a specific locale instead of following the user's browser locale.

```html
<forge-timestamp datetime="2024-03-15T14:30:00" locale="fr-FR"></forge-timestamp>
```

## Separators

Set `separator` to `before` or `after` to place a dot next to the timestamp, visually separating it from adjacent inline content. The default is `none`.

<Example description="A timestamp with a leading separator dot, next to other inline content.">
  <span>Updated <forge-timestamp datetime="2024-03-15T14:30:00" format="MMMM dd" separator="before"></forge-timestamp></span>
</Example>
