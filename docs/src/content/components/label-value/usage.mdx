## Usage

`forge-label-value` displays a readonly `label` and `value` pair, with an optional leading `icon` slot, plus `empty`, `ellipsis`, and `inline`. Use it for data the user can view but not edit, most often inside a <a href={`${import.meta.env.BASE_URL}components/card/usage/`}>card</a> or a submitted form; reach for a <a href={`${import.meta.env.BASE_URL}components/text-field/usage/`}>text field</a> with `disabled` instead only when the value is still part of an editable form. For long, text-heavy content, use a list instead — label value is meant for succinct data.
