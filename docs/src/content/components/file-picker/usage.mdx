## Usage

`forge-file-picker` combines a drag-and-drop target with a slotted trigger <a href={`${import.meta.env.BASE_URL}components/button/usage/`}>button</a>, controlled through `accept`, `max-size`, `capture`, `multiple`, `disabled`, `compact`, and `borderless`. The component only handles the picking gesture; render uploaded files yourself afterward, typically as a list with a progress indicator per file while it uploads.

<InlineMessage theme="warning">
  Always set `type="button"` on the slotted trigger button — without it, clicking the trigger inside a `<form>` submits that form. The system file-chooser dialog also returns focus to whichever element triggered it, so don't move focus yourself once it closes.
</InlineMessage>

```html
<forge-file-picker>
  <button slot="trigger" type="button">Select files</button>
</forge-file-picker>
```
