## Usage

`forge-date-range-picker` wraps a <a href={`${import.meta.env.BASE_URL}components/text-field/usage/`}>text field</a> with two inputs — "from" and "to" — and adds a calendar popup for picking both ends of a range, through `from`, `to`, `min`, `max`, `disabledDates`, `disabledDaysOfWeek`, `masked`, `showToday`, and `showClear`. Use it whenever a user is entering a span of dates, like time off or a project's start and end; for a single date, use a <a href={`${import.meta.env.BASE_URL}components/date-picker/usage/`}>date picker</a> instead.

## Masking

Set `masked` to apply an input mask, shown as a placeholder in each field, so typed dates are corrected to a consistent format as the user types.
