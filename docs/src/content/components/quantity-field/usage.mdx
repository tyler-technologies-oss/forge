## Overview

The quantity field wraps a native number input with a decrement button on one side and an increment button on the other. It is built for small, bounded counts, like the number of items to order or attendees to register, where stepping up and down is faster than typing. It's typically used in forms and carts alongside other form fields.

## Usage

`forge-quantity-field` wraps a native `<input type="number">` in its default slot, with a `label` slot for the visible label and a `support-text` slot for hints and error messages. The input's `min`, `max`, and `step` attributes control the range and the amount each button click changes the value. Set `invalid` and `required` on the field to reflect validation state. Use `decrement-label` and `increment-label` to customize the buttons' accessible names, or replace the buttons and their icons through the `decrement-button`, `decrement-icon`, `increment-button`, and `increment-icon` slots. Use it for small numeric values; for free-form or large numbers, use a <a href={`${import.meta.env.BASE_URL}components/text-field/usage/`}>text field</a> with a number input instead.
