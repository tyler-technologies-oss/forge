## Usage

`forge-app-layout` scaffolds an entire application: an <a href={`${import.meta.env.BASE_URL}components/app-bar/usage/`}>app bar</a> with logo, title, and actions; a navigation <a href={`${import.meta.env.BASE_URL}components/drawer/usage/`}>drawer</a> that sits beside the body on large screens and becomes a modal drawer on small ones; and a body area with optional header, footer, and side panels. Start every Forge app with it, put page content in the `body` slot, and let the layout handle responsiveness.
