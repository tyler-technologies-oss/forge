## Usage

`forge-banner` displays a persistent, page-level message through `theme`, `dismissed`, and `persistent`, plus optional `icon` and `button` slots. Reserve it for a full-page announcement the user only needs to see once; for guidance scoped to a single field or section, use an <a href={`${import.meta.env.BASE_URL}components/inline-message/usage/`}>inline message</a> instead, for a reactive confirmation of an action use a <a href={`${import.meta.env.BASE_URL}components/toast/usage/`}>toast</a>, and for a high-priority alert that requires a decision use a <a href={`${import.meta.env.BASE_URL}components/dialog/usage/`}>dialog</a>.

## Theme

Set `theme` to `primary`, `secondary`, `tertiary`, `success`, `error`, `warning`, `info` (the default), or `info-secondary` to match the message's severity.

## With an icon and action

Pair the message with a leading icon in the `icon` slot to reinforce its severity, and a trailing action in the `button` slot when there's more detail to show.
