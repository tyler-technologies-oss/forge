## Usage

`forge-label` provides an accessible caption and Forge typography for a specific set of label-aware components — <a href={`${import.meta.env.BASE_URL}components/button/usage/`}>button</a>, <a href={`${import.meta.env.BASE_URL}components/checkbox/usage/`}>checkbox</a>, <a href={`${import.meta.env.BASE_URL}components/icon-button/usage/`}>icon button</a>, <a href={`${import.meta.env.BASE_URL}components/radio/usage/`}>radio</a>, <a href={`${import.meta.env.BASE_URL}components/select/usage/`}>select</a>, <a href={`${import.meta.env.BASE_URL}components/switch/usage/`}>switch</a>, and button toggle groups — through `for` (explicit ID association), `legend`, and `non-interactive`. It isn't a general-purpose replacement for a plain `<label>` — it only works when paired with one of these specific elements, so reach for a native `<label>` (or `aria-label`) when labeling anything else, including <a href={`${import.meta.env.BASE_URL}components/text-field/usage/`}>text fields</a>, which manage their own label internally.
