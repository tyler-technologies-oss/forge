## Usage

`forge-list` groups `forge-list-item` children through `dense`, `twoLine`/`threeLine`, `wrap`, `multicolumn`, and `navlist`, while each item carries its own `selected`, `value`, and `start`/`end` slots. Use a list for related, primarily textual items; for content with three or more sortable dimensions, use a <a href={`${import.meta.env.BASE_URL}components/table/usage/`}>table</a> instead, and for content built around imagery or non-homogeneous data, use a <a href={`${import.meta.env.BASE_URL}components/card/usage/`}>card</a> instead.

## As navigation

Set `navlist` on the list and pair each item with a leading icon and an anchor — the pattern used inside a <a href={`${import.meta.env.BASE_URL}components/drawer/usage/`}>drawer</a>. Mark the active item with its own `selected` attribute, or set `selectedValue` on the list to match an item's `value` — either way, also add `aria-current="page"` to that item, since that's the attribute screen readers actually rely on to announce it as the current page.

## Expandable items

Nest an <a href={`${import.meta.env.BASE_URL}components/expansion-panel/usage/`}>expansion panel</a> inside a list item to show or hide additional content or a sub-list. Put that content in an element with `slot="additional-content"` — that's required for it to be visually and structurally separated from the item's main content, and announced correctly by screen readers.

```html
<forge-list-item>
  Item with more detail
  <forge-expansion-panel slot="additional-content">
    <p>Additional detail shown when expanded.</p>
  </forge-expansion-panel>
</forge-list-item>
```
