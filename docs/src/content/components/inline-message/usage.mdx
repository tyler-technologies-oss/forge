## Usage

`forge-inline-message` communicates persistent, contextual guidance through `theme`, with optional `icon` and `title` slots. Place it directly beside or inside the component it refers to, such as a form, field, or card. For a page-level announcement, use a <a href={`${import.meta.env.BASE_URL}components/banner/usage/`}>banner</a> instead; for a reactive confirmation of an action, use a <a href={`${import.meta.env.BASE_URL}components/toast/usage/`}>toast</a> instead; for high-priority information that needs a decision, use a <a href={`${import.meta.env.BASE_URL}components/dialog/usage/`}>dialog</a> instead.

## Theme

Set `theme` to `error`, `warning`, `success`, `info` (the default), or `info-secondary` to match the message's meaning, and pair it with an icon in the `icon` slot that reinforces the same meaning.
