## Overview
Switches are selection controls that allow users to toggle a single setting between two states: on/off, show/hide, etc. They appear as a sliding toggle with a marker that moves between positions to indicate the current state.

Switches provide immediate feedback and typically take effect instantly when toggled, making them ideal for settings that users want to control in real-time without requiring form submission.

## Usage

`forge-switch` toggles a single, independent setting on or off through `checked`, participates natively in form submission and validation (`required`, `readonly`, `name`, `value`), and supports `dense`, `icon`, and `label-position`. It's the third of three selection controls: reach for a <a href={`${import.meta.env.BASE_URL}components/checkbox/usage/`}>checkbox</a> instead when a user can select zero, one, or many options from a list, or a <a href={`${import.meta.env.BASE_URL}components/radio/usage/`}>radio button</a> instead when exactly one option in a visible set must be chosen.
