## Keyboard interaction and ARIA

Tree implements the keyboard shortcuts and ARIA roles, states, and properties defined in the <a href="https://www.w3.org/WAI/ARIA/apg/patterns/treeview/">WAI-ARIA Tree View pattern</a> — arrow keys move focus between items, and the expanded/selected state of each item is exposed automatically. You don't need to hand-wire ARIA attributes yourself.
