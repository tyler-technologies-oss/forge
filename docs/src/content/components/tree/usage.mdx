## Usage

`forge-tree` nests `forge-tree-item` children to let a user navigate hierarchical data, through `mode` (`single`, `multiple`, `leaf`, or `off`), `accordion`, `indentLines`, `selectionFollowsFocus`, and `disabled`, while each item carries its own `open`, `selected`, `lazy`, and `disabled` state. Use it for genuinely hierarchical data — folders, nested categories, an org chart; for a flat set of items, use a plain <a href={`${import.meta.env.BASE_URL}components/list/usage/`}>list</a> instead.

## Basic usage

Nest `forge-tree-item` elements inside each other to build the hierarchy; each item's `value` identifies it when selected.

<Example description="A tree with nested items, one expanded to show its children.">
  <forge-tree>
    <forge-tree-item value="documents" open>
      Documents
      <forge-tree-item value="report">Report.docx</forge-tree-item>
      <forge-tree-item value="budget">Budget.xlsx</forge-tree-item>
    </forge-tree-item>
    <forge-tree-item value="photos">Photos</forge-tree-item>
  </forge-tree>
</Example>

## Selection

Set `mode` to `single` (the default) or `multiple` to control how many items can be selected at once, or `leaf` to only allow selecting items with no children. Set `mode="off"` to disable selection entirely, and `selectionFollowsFocus` to select an item as soon as it's focused (single mode only).

## Accordion behavior

Set `accordion` so opening one item automatically closes its siblings, instead of allowing multiple branches open at once.

## Lazy loading

Set `lazy` on a `forge-tree-item` for a node whose children should be fetched or rendered only when the item is first opened, rather than up front.
