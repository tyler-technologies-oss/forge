## Usage

`forge-toast` shows a brief, temporary confirmation through `open`, `duration`, `placement`, and `theme`, plus an optional `actionText` and `dismissible` close button. Trigger it imperatively by setting `open` (or calling the static `ToastComponent.present(...)` helper) in response to a user action; reserve it for confirming something that just happened, and show only one at a time. For a message that requires a decision, use a <a href={`${import.meta.env.BASE_URL}components/dialog/usage/`}>dialog</a> instead; for a page-level announcement, use a <a href={`${import.meta.env.BASE_URL}components/banner/usage/`}>banner</a> instead.

## Basic usage

A trigger fires the action, then sets the toast's `open` property (or calls `ToastComponent.present(...)`) to show it. A toast shown via `ToastComponent.present(...)` removes itself from the DOM once `duration` elapses; a declarative `<forge-toast open>` does not — toggle `open` yourself to hide it.

## With dialogs

<InlineMessage theme="warning">
  A dismissible toast shown while a `forge-dialog` is open is non-interactive by default — the dialog makes everything outside it `inert`. Pass `topLayer: true` to keep it clickable; this appends the toast to the topmost open dialog instead of the page.

  ```js
  ToastComponent.present({ message: "Save successful", topLayer: true });
  ```
</InlineMessage>
