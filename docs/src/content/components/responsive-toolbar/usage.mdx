## Overview

The responsive toolbar is a toolbar that adapts its actions to the space available. When there is room, it shows the full set of actions; when the title would collide with them, it swaps to a compact version. It's typically used at the top of a card, panel, or page section whose width changes, such as a resizable panel or a narrow viewport.

## Usage

`forge-responsive-toolbar` extends the <a href={`${import.meta.env.BASE_URL}components/toolbar/usage/`}>toolbar</a> with two end slots. Put the full set of actions, like a row of buttons, in `end-large`, and a compact alternative, like an icon button that opens a <a href={`${import.meta.env.BASE_URL}components/menu/usage/`}>menu</a>, in `end-small`. The toolbar shows `end-large` while the title doesn't overlap the actions and `end-small` once it does. The `before-start`, `start`, and `after-end` slots map to the toolbar's slots of the same names, and the `no-border` and `inverted` properties control the divider. Listen for `forge-responsive-toolbar-update` to react to the change, and use `resize-delay` to tune how often resizes are checked. Use it when the toolbar's width changes; for a fixed-width toolbar, use a plain toolbar.
