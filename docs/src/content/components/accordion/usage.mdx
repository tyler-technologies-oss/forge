## Usage

`forge-accordion` wraps a set of <a href={`${import.meta.env.BASE_URL}components/expansion-panel/usage/`}>expansion panel</a> children and closes any other open panel whenever one of them opens, through its `panelSelector` property for scoping to panels that aren't direct children. It adds no visual styling of its own; pair it with a <a href={`${import.meta.env.BASE_URL}components/divider/usage/`}>divider</a> between panels for visual separation. If a design calls for more than one panel open at a time, skip the accordion wrapper entirely and use expansion panels on their own.

## Basic usage

Give each panel a `header`-slotted button; opening one panel automatically closes any other open panel in the same accordion.
