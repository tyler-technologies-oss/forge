## Usage

`forge-circular-progress` communicates that a single component or a small area of the page is loading or changing, through `determinate`, `progress`, `theme`, and `track`. Place it close to the content it describes, such as inside a <a href={`${import.meta.env.BASE_URL}components/button/usage/`}>button</a>, a list item, or a card, rather than for the whole page. For a page-level or full-region block, use a busy indicator instead, and for a horizontal, linear alternative, use a <a href={`${import.meta.env.BASE_URL}components/linear-progress/usage/`}>linear progress</a> indicator instead.
