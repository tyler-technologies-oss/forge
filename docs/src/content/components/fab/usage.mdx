## Usage

`forge-fab` represents a page's single most important action through `theme`, `density`, and `elevation`. Use the default slot alone for an icon-only FAB, or add the `label` slot for an extended FAB with a text label. Reserve it for pages that truly have one primary action; when several actions are equally likely, reach for a <a href={`${import.meta.env.BASE_URL}components/button/usage/`}>button</a> instead.

## Positioning

`forge-fab` doesn't position itself — fix it to a corner of the viewport (or a scroll container) yourself, typically with `position: fixed` and a spacing token for the offset:

```css
.bottom-right {
  position: fixed;
  bottom: var(--forge-spacing-medium);
  right: var(--forge-spacing-medium);
}
```
