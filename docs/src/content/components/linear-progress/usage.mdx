## Usage

`forge-linear-progress` communicates that a component is loading through `determinate`, `progress`, `buffer`, and `theme`. Reach for it at the bottom of a field, dropdown, or expansion panel; for a spinner that fits inside a smaller component like a button, list item, or card, use a <a href={`${import.meta.env.BASE_URL}components/circular-progress/usage/`}>circular progress</a> indicator instead.

## Determinate

Set `determinate` and `progress` (a value from `0` to `1`) when the actual completion percentage is known.

## Buffer

Set `buffer` (a value from `0` to `1`) alongside `progress` to show a second, lighter fill for content that's ready but not yet the active position — the pattern used by media scrubbers.
