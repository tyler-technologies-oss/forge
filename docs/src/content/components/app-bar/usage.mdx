## Overview

The app bar serves as a user's primary navigation hub, containing everything needed to navigate within the current application, access other applications, and customize their experience. It provides persistent access to essential functionality including application identity, search capabilities, notifications, help resources, and user account management across all application contexts.

The app bar maintains consistent placement and functionality across different screen sizes and device types, ensuring users always have access to core navigation and utility functions regardless of their current location within the application.

## Usage

`forge-app-bar` lays out branding and top-level actions through its `logo`, `title`, `start`, `center`, and `end` slots, plus `elevation`, `theme`, and `themeMode`. Reserve the `start` slot for navigation (typically a menu button that opens a <a href={`${import.meta.env.BASE_URL}components/drawer/usage/`}>drawer</a>), the `center` slot for app-wide search, and the `end` slot for a small set of purpose-built buttons: help, notifications, an app launcher, and the user's profile.

## Theme

Set `theme` to tint the app bar, and `themeMode` to `inherit` (the default, applying that theme globally to the app bar and its children) or `scoped` (limiting it to just the app bar itself).

<Example

/>

### Theming pitfalls

<InlineMessage theme="warning">
  With the default `themeMode="inherit"`, global theme tokens cascade to every child element — including popovers and dialogs opened from the app bar, which can end up styled with the wrong colors. Switch to `themeMode="scoped"` to stop that cascade.
</InlineMessage>

Scoping the theme comes with a tradeoff: elements placed directly in the app bar no longer inherit its colors automatically either. Set `theme="app-bar"` to opt a child back in — but it's only supported on `forge-button`, `forge-icon-button`, and `forge-tab-bar`. The app bar's own preset buttons (menu, help, notification) and `forge-user-profile` already set this for you.

For any other element, reference the app bar's scoped tokens directly — `--forge-app-bar-theme-foreground` and `--forge-app-bar-theme-background-muted`:

```css
forge-app-bar forge-avatar {
  --forge-avatar-background: var(--forge-app-bar-theme-foreground);
  --forge-avatar-color: var(--forge-theme-text-high);
}
```

## User profile

Use `forge-user-profile` in the `end` slot to show the signed-in user. It renders an avatar button that opens a popover with their `fullName` and `email`, any `link`-slotted profile links, an optional `themeToggle`, and a sign-out action, firing `forge-user-profile-sign-out` when it's clicked.

<InlineMessage theme="warning" title="Deprecated">
  `forge-app-bar-profile-button` is deprecated in favor of `forge-user-profile`. It remains available but is frozen — no new features, and possible removal in a future release.
</InlineMessage>
