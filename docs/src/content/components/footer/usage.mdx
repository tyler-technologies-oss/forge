## Overview

A footer sits at the bottom of an app or page and holds the content users rarely need but should always be able to find: links to about, contact, and privacy pages, copyright text, and a brand graphic. It adapts to the available width, laying items out in a row on wide screens and stacking them on narrow ones.

Footers are typically paired with an <a href={`${import.meta.env.BASE_URL}components/app-layout/usage/`}>app layout</a>, which places the footer below the main content.

## Usage

`forge-footer` wraps one `forge-footer-item` per link or line of text, and accepts a `graphic` slot for a logo. Set `layout` to `standard`, `alternative`, or `auto` (the default); in `auto`, the footer switches to the alternative layout below `layoutBreakpoint` (900px by default). Use a footer for persistent, low-priority links and legal text; for primary navigation, use a <a href={`${import.meta.env.BASE_URL}components/tabs/usage/`}>tab bar</a> or drawer instead.
