## Usage

`forge-calendar` selects one or more dates through `mode` (`single`, `multiple`, or `range`), plus `min`/`max`/`disabledDates`/`disabledDaysOfWeek` constraints, `events`, and `view`. Use it when the task is calendar-driven and the surrounding days give useful context, like picking a day off. Reach for a <a href={`${import.meta.env.BASE_URL}components/date-picker/usage/`}>date picker</a> instead when a user is typing in a familiar date and screen space is limited, or a <a href={`${import.meta.env.BASE_URL}components/date-range-picker/usage/`}>date range picker</a> instead for a bounded start/end range in that same compact form.

## Selection mode

Set `mode` to `single` (the default), `multiple` for several non-chronological dates, or `range` for a bounded start and end date.
