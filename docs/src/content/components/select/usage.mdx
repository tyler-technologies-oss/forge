## Usage

`forge-select` presents a list of `forge-option` (optionally grouped with `forge-option-group`) inside a field frame, and supports `label`, `placeholder`, `multiple`, and `showSelectAll`. Use it to recommend a default from a closed set of options; reach for a <a href={`${import.meta.env.BASE_URL}components/autocomplete/usage/`}>autocomplete</a> instead once a list runs past 10 or so options, or a <a href={`${import.meta.env.BASE_URL}components/radio/usage/`}>radio group</a> instead when every option must stay visible for comparison.

## Select all

Pair `multiple` with `showSelectAll` to add a "select all" option above the list — set `selectAllLabel` to customize its text.

<Example
  description="showSelectAll adds a select-all option above a multiple select's list."
  blockUrl="https://forge.tylerdev.io/blocks/v1/components/select/select-all/select-all.html"
  height="300px"
/>

Clicking "select all" fires `forge-select-all` before the standard `change` event, with `detail.value` (every option's value, or an empty array when deselecting) and `detail.isAllSelected`. Calling `preventDefault()` on `forge-select-all` also suppresses the `change` event that would otherwise follow it.

```js
selectEl.addEventListener("forge-select-all", (event) => {
  if (!userMaySelectAll) {
    event.preventDefault();
  }
});
```
