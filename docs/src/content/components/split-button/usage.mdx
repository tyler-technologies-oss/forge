## Usage

`forge-split-button` groups two or more slotted `forge-button` children into a single visual unit, propagating `variant`, `theme`, `disabled`, `dense`, and `pill` to every button so they render consistently. Pair a primary action with a `forge-menu` trigger for a classic split button, or slot several buttons directly for a segmented group of equally-weighted actions. For actions that aren't related to one another, use individual <a href={`${import.meta.env.BASE_URL}components/button/usage/`}>buttons</a> or <a href={`${import.meta.env.BASE_URL}components/icon-button/usage/`}>icon buttons</a> instead.
