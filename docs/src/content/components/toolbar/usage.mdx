## Usage

`forge-toolbar` aligns content to `before-start`, `start`, `center`, `end`, and `after-end` slots inside a full-width container, through `inverted`, `noDivider`, `noPadding`, and `autoHeight`. Use it as a header or footer inside a <a href={`${import.meta.env.BASE_URL}components/scaffold/usage/`}>scaffold</a> or <a href={`${import.meta.env.BASE_URL}components/dialog/usage/`}>dialog</a>, as a section within a <a href={`${import.meta.env.BASE_URL}components/drawer/usage/`}>drawer</a>, or anywhere else a title and actions need consistent alignment.

## Structure

Every slot at once shows how the toolbar positions content: `before-start` and `after-end` sit outside the main three, which align to `start`, `center`, and `end`.

## Inverted

Set `inverted` to move the toolbar's divider from the bottom edge to the top — use it on a footer toolbar, where the divider should separate it from the content above rather than below.
