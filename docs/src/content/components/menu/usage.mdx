## Usage

`forge-menu` wraps a trigger element and opens a dropdown of `options` — icon-and-label entries, optionally grouped, set as a JS property rather than an attribute — through `mode` (`click` or `cascade`), `placement`, and `dense`. Reserve it for a short list of contextual actions or unrelated options; for a field where a user picks one value from a fixed set, use a <a href={`${import.meta.env.BASE_URL}components/select/usage/`}>select</a> instead — the menu's own `selectedIndex`/`selectedValue` are deprecated for exactly that reason.

## Basic usage

Wrap a trigger element — typically a button — in `forge-menu` and set its `options` property to populate the dropdown.

<Example
  description="A menu opened from a button trigger."
  blockUrl="https://forge.tylerdev.io/blocks/v1/components/menu/demo/demo.html"
  height="200px"
/>

Add an icon to an option with `icon` (or `leadingIcon`/`trailingIcon` to be explicit about placement), plus a matching `leadingIconType`/`trailingIconType` set to `"component"` to render it as a real `forge-icon` element:

```js
const options = [
  { label: "Edit", value: "edit", leadingIcon: "edit", leadingIconType: "component" },
  { label: "Delete", value: "delete", leadingIcon: "delete", leadingIconType: "component" },
];
```
