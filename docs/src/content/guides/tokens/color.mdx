The Forge theme is built on a set of tokens that define the colors used throughout the design system. These tokens are used to
define the colors of the components and the overall look and feel of the design system.

## Emphasis

The emphasis tokens define the opacity levels applied to the on-surface color to create varying levels of visual emphasis. The preview shows the on-surface color at each level.
